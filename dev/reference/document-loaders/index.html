    Document Loaders¶

    Document loaders retrieve remote JSON-LD documents and contexts. PyLD ships class-based loaders for common cases and supports custom subclasses of DocumentLoader.

    • RequestsDocumentLoader

      Synchronous remote document loading with requests.

    • SqliteCacheRequestsDocumentLoader

      Persistent SQLite caching for remote JSON-LD documents.

    • AioHttpDocumentLoader

      Asynchronous fetching with aiohttp while JSON-LD processing stays synchronous.

    • FrozenDocumentLoader

      Serve only documents from an allowlist for air-gapped or reproducible runs.

    • FileDocumentLoader

      Read local JSON-LD documents from file: URLs.

    • SchemeDirectedDocumentLoader

      Delegate to another Document Loader based on the scheme of the URL, for instance, file: vs https://.

    • TypeDirectedDocumentLoader

      Delegate by Python input type, for instance pathlib.Path vs URL str.

    • Custom Document Loaders

      Subclass DocumentLoader for application-specific loading logic.

    Default Document Loader¶

    The default document loader is selected at import time, in this order:

    1. RequestsDocumentLoader if requests is available
    2. AioHttpDocumentLoader if aiohttp is available

    If neither is installed, document loading raises.
